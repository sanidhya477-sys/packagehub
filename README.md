# PackageHub Starter

A Next.js starter for a package/service website with:
- Home
- Login demo
- Packages
- Payment placeholder
- User dashboard
- Admin panel

## Run
1. Install Node.js 20+.
2. Run `npm install`
3. Run `npm run dev`
4. Open http://localhost:3000

## Production checklist
Use a licensed payment gateway and verify webhooks server-side. Add real authentication, database persistence, RBAC, audit logs, rate limiting, secure secrets, privacy/terms pages, refund handling, and a legal/compliance review.

This starter intentionally does NOT implement a guaranteed-return investment/recharge scheme or direct collection of UPI credentials.
